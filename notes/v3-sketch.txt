## The V3 core experiment: an abstraction is born

World: the task-group-family promotion testbed (prediction
P-2026-08-18-D). Family components are assigned per TASK GROUP —
cross-cutting structure that a task-invariant shared basis cannot
absorb — fixing the Benchmark E design flaw (its primitive-indexed
hierarchy was absorbable; residuals carried nothing shared; measured
negative in reports/v2_hierarchical/). Family identities are never
exposed. Structureless control worlds (rho = 0 analogue) run paired.

Learner, wake phase (manifold-first, bits-priced):
- Shared substrate: hypernetwork-style generated operators (006b/002b:
  mixtures are manifold solutions; the pure manifold wins at partial
  recurrence; do not presuppose slots).
- Task state: variational-coded residuals — q(Delta_tau) with learned
  per-parameter precision, KL to a shared prior in the wake loss:
      J_wake = L_preq + beta * KL(q(Delta_tau) || p(Delta))
  Bits are in the gradient DURING learning (the root fix for every V2
  compression failure). Only irreversible discrete restructuring is
  sleep-only.

Sleep phase (one operation: PROMOTE):
- Detect recurring residual structure FUNCTIONALLY (behavioral
  similarity on probes, adapters permitted: F_i ~ B_i A(A_i z)), never
  by parameter identity — constitutional law from V2's instrument
  failures.
- Promote candidate A iff the full accounting improves:
      D(A) + sum_i D(epsilon_i | A) + D(references) + lambda*dL + mu*dC
      <  sum_i D(Delta_i)
- The rate-distortion form R(epsilon) (shortest description preserving
  behavior to tolerance) replaces exact-identity compression and
  single-lambda accounting where practical; report the bits-fidelity
  Pareto rather than one point.

## H11 — Abstraction Promotion Hypothesis (three required predictions)

When task-specific continuous adaptations contain recurrent functional
structure, a learner charged for their information content reduces total
lifetime description length by promoting that structure into shared
abstractions:
1. D_promoted < D_unpromoted at matched predictive loss (the bits-flow
   figure: task bits fall, shared bits rise, total bits fall, prediction
   flat);
2. J_promoted < J for shared-residual, Continuous, AND Dense in
   hierarchical/mixed worlds — the first model to win both currencies;
3. PROSPECTIVE (M3, added per review 14): after promotion, RELATED
   future tasks cost measurably fewer samples/nats to learn than for the
   unpromoted control — compression without forward benefit is storage
   optimization, not abstraction.
And: NO promotion in structureless controls. A promoter that cannot
refuse is not a criterion.

H12 — Hierarchical Vocabulary: with sharing structure at several levels,
repeated promotion recovers the world's latent hierarchy functionally
(global vs family vs task strata), without being given identities.

## Design principles (binding, all evidence-derived)

- Functional instruments only; nothing downstream of the library may
  reference identities (V2's uniform instrument failures).
- Program synthesis (fast, per-problem, over the existing language) and
  language revision (slow, consolidation-only) are strictly separate —
  "the model programs itself" means the former, never online
  self-modification.
- Parsimony is endogenous: price persistent bits and execution; never
  hardcode "fewer modules" or "shorter programs"; interpreter-vs-
  compiler economics falls out of lambda/mu.
- Learning progress is conditional description length: D(F | L_t)
  decreasing in t — the language improves so future experience is
  cheaper to describe and to learn (ties compression to sample
  efficiency; the M3 test operationalizes it).
- One surrendered control per rung; sealed seeds 300-329 with the
  parameter-interval discipline inherited from V2.

## Deferred workstreams (unchanged destinations, stricter gates)

- Cross-world scale (V3b/Phase III): the expert-iteration loop (search
  -> distill -> dream -> verify) trained across thousands of worlds;
  justified by H10's sample-starvation profile; measure the G(N)
  amortization crossover rather than retrying bigger; lifetime/meta
  controls travel with it. Observable recurrence estimators (gradient
  alignment, one-step transfer) validated against ground truth are the
  prerequisite for any learner that must sense reuse without oracle rho.
- LLM bridge, staged measure -> factor -> learn: LLM-A, does estimated
  functional recurrence (functional-effect probes over frozen-model
  adapters, not weight similarity) predict sharing benefit — export the
  V1 law first; LLM-B, shared-plus-residual factoring of adaptations;
  LLM-C, dynamic promotion. Never build LLM-C before A and B hold.
- ROW-P (programmable perception) and Benchmark C stand as before,
  behind their own gates.
