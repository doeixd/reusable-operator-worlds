## 2. Remaining items, in priority order

### 2.1 Finish the family-mismatch sweep (two runs)

`decoupled_tanh` still keeps the teacher's activation and rank, so the
family-inheritance objection is only one-third answered. The two runs that
actually break the family, and that a skeptical reader will ask for first:

- gelu operators: `--model continuous --operator-activation gelu` (seed 0);
- rank mismatch: `--teacher-rank 16` with learner rank 8 (seed 0).

The CLI flags exist; this is two commands. Run these BEFORE stage-2 tuning:
a surprise here changes what is being tuned. Amend reviewer-02's 8-step
sequence accordingly.

### 2.2 Re-run the oracle gate once

The oracle config also changed (alpha now 0.2 and learnable). The positive
control was passed under fixed alpha 0.35. Before citing oracle numbers in
any write-up, re-run the oracle once so the reported gate matches the
current code. One run.

### 2.3 Exclude learnable alpha from weight decay

The learnable alpha scalar lands in `shared_parameters()` and therefore in
the AdamW group with weight_decay 1e-4, which pulls alpha toward zero.
Almost certainly negligible, but for a public artifact it is cleaner to put
alpha scalars in a no-decay parameter group. One line per model.

### 2.4 Still open from feedback-01 (unchanged priorities)

- Per-task discrete temperature annealing (feedback-01 section 2.2). The
  global anneal remains a plausible artifactual explanation for the
  "route inference is the bottleneck" narrative. One run, seed 0.
- Identity-operator ablation for the continuous basis (section 2.3). One
  line, one run; also the cheapest datapoint on variable effective depth.
- `forward_tasks` batching by task ID. Still the best compute ROI in the
  repo; matters more as the rho sweep and stage-2 tuning approach.
- Reporting normalization: per-example nats/bits alongside totals; paired
  per-world deltas instead of n=3 bootstrap intervals; scope the
  "compute-matched" claim to inference multiply-adds or report training
  FLOPs separately.

### 2.5 Repo hygiene

  Commit it (alpha decoupling + configs + family control artifact
