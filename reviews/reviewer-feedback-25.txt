# The simultaneous “smaller + better” result deserves a frozen diagnostic

I suspect promotion is denoising.

Twenty-four private residuals are independent noisy estimates of some underlying family computation. Functional fitting pools them:

[
R_1,\ldots,R_n
\rightarrow
A.
]

So (A) may be a better estimate of the actual recurring computation than any individual (R_i).

Test post-hoc:

[
d(A,F_{\rm teacher})
]

versus:

[
\operatorname{median}*i d(R_i,F*{\rm teacher}).
]

Teacher access is fine for this analysis instrument.

If:

[
d(A,F^*)<d(R_i,F^*),
]

you have a beautiful explanation:

[
\boxed{
\textbf{Abstraction pays twice: amortization compresses repeated information,
and pooling repeated evidence improves estimation.}
}
]

That could explain the (+1,350)-nat predictive gain rather than leaving it as a pleasant surprise.

Again: diagnostic, not sealed criterion.

## And I'd be precise about what V3 would establish if sealed replicates

Not:

> neural networks spontaneously invent abstractions in general.

And not:

> MDL automatically produces programs.

Rather:

> **In a controlled continual-learning environment where recurring private computation is behaviorally reusable but cannot be absorbed by existing shared capacity, an explicit promotion mechanism can identify that recurrence functionally, create new addressable shared computation, replace repeated task-local information with references, reduce total retained description length, and lower the learning cost of subsequent related tasks.**

That is already a substantial result.

And I think the most important conceptual upgrade from the four failed testbeds is:

[
\boxed{
\text{PROMOTE should not mean “find something similar.”}
}
]

It means:

[
\boxed{
\textbf{find private computation that is load-bearing,
cross-task substitutable,
more specific than a generic shared approximation,
and valuable on data it was not fitted to;
then allocate shared capacity to it.}
}
]

That's a far more defensible definition of abstraction than where V3 began.

If the 30 sealed worlds replicate roughly what you're seeing now, I would regard **the base case of Neural Library Learning as experimentally demonstrated**. The next question then really is whether the mechanism recurses: can these newly born abstractions themselves become components of higher-level abstractions?
